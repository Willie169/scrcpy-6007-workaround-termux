This repo aims to build [scrcpy](https://github.com/Genymobile/scrcpy) Termux package using server with [issue 6007 workaround](https://github.com/Genymobile/scrcpy/issues/6007#issuecomment-4444559534) for Samsung from my [scrcpy-6007-workaround](https://github.com/Willie169/scrcpy-6007-workaround) repo's release using GitHub Action. For other platforms, go to my [scrcpy-6007-workaround](https://github.com/Willie169/scrcpy-6007-workaround) repo. You need to keep your phone unlocked to keep your scrcpy session unlocked.

This repo is licensed the same as the [original script](https://github.com/termux/termux-packages/blob/master/x11-packages/scrcpy/build.sh).
