This repo aims to build [scrcpy](https://github.com/Genymobile/scrcpy) Termux package with [issue 6007](https://github.com/Genymobile/scrcpy/issues/6007) workaround for Samsung using GitHub Action. For other platforms, go to [scrcpy-6007-workaround](https://github.com/Willie169/scrcpy-6007-workaround).

This repo is licensed the same as the [original script](https://github.com/termux/termux-packages/blob/master/x11-packages/scrcpy/build.sh).
